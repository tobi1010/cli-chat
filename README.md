# <Project Name>

Minimal Go app using the OpenAI API.

## Requirements

- Go (recent version)
- An OpenAI API key

## Configuration

This app currently supports **OpenAI only**.

Set your API key as an environment variable:

- `OPENAI_API_KEY`

Example:

```bash
export OPENAI_API_KEY="your_api_key_here"
```

**Don’t commit API keys to the repository**

More flexible key/config resolution will be added later.
